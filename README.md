# StoryFoundry

StoryFoundry is a Next.js web app that drafts cinematic content packs for faceless YouTube creators. It provides a dashboard to generate placeholder titles, hooks, scripts, image prompts, and thumbnail text ideas for true crime, dark real-life, and psychological stories.

## Tech stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the app.
